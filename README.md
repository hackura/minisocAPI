# MiniSOC API

A lightweight defensive Security Operations Center (SOC) API built with Python and FastAPI.

## Goals

MiniSOC demonstrates practical blue-team concepts through a REST API that ingests security events, evaluates risk, detects suspicious authentication activity, and produces SOC alerts.

## Planned capabilities

- Security event ingestion
- Failed-login and brute-force detection
- Risk scoring and severity classification
- SOC alert generation
- MITRE ATT&CK technique mapping
- SQLite development database with PostgreSQL-ready design
- Input validation and structured logging
- Automated tests
- OpenAPI/Swagger documentation
- Docker and GitHub Actions support
